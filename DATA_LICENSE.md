# Data Rights and Reuse

## Project-authored annotations and metadata

Unless otherwise marked, project-authored COCO annotations, de-identified indexes, and non-sensitive metadata are
intended for release under the Creative Commons Attribution 4.0 International license (CC BY 4.0).

## Image pixels

Image pixels are not automatically covered by the CC BY 4.0 license above. Copyright, related rights, cultural-
heritage image-management rights, and contractual restrictions for color test tiles and grayscale derivatives remain
with the original rights holders or data providers. Before public upload, the project owner must confirm the right to
copy and distribute these images in a public repository. Image files must not be pushed publicly without confirmation.

## Excluded data

Precise geographic locations, personal data, security information, unauthorized color field photographs, and other
confidential materials are not part of this data release.
