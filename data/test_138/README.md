# Public Test Set

This directory contains the fixed held-out split used for quantitative Mask R-CNN evaluation.

- Images: 138
- Person instances: 422
- Format: COCO instance segmentation
- Category: `person`
- Split seed: 42

`test_index.csv` records temple codes, temple names, image dimensions, person-instance counts, and SHA-256 checksums.

The color test images may be pushed to a public repository only after the project owner confirms public-distribution
rights. See `../../DATA_LICENSE.md` and `../../docs/PUBLISHING_CHECKLIST.md`.

# 公开测试集

本目录保存Mask R-CNN量化测试使用的固定留出测试集。

- 图片：138张
- 人物实例：422个
- 格式：COCO实例分割
- 类别：`person`
- 数据划分随机种子：42

`test_index.csv`记录寺庙编号、寺庙名称、图片尺寸、人物实例数和SHA-256校验值。

彩色测试图片只有在项目负责人确认公开传播权后才能推送到公开仓库。权利边界见
`../../DATA_LICENSE.md`和`../../docs/PUBLISHING_CHECKLIST.md`。
