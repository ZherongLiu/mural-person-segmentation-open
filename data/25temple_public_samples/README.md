# Public Samples from 25 Temples

This directory provides one public display sample for each of the 25 temples represented in the project, for a total
of 25 samples.

Publication controls:

- only one sample per temple;
- grayscale derivatives only;
- maximum dimension of 1024 pixels;
- no original color field photographs;
- no original directory paths, precise coordinates, personal data, or confidential conservation records;
- only the source SHA-256 is retained for internal provenance checking; the original file name is not disclosed.

These files are public demonstration derivatives and do not mean that the complete high-resolution archive for all
25 temples has been released.

# 25庙公开样例

本目录为项目涉及的25座庙宇各提供1张公开展示样例，共25张。

公开控制规则：

- 每座庙宇只放1张；
- 只使用灰度派生图；
- 最长边不超过1024像素；
- 不包含彩色原始实拍图片；
- 不包含原始目录路径、精确坐标、个人信息和保密修缮资料；
- 仅保留源文件SHA-256，用于内部证据追溯，不公开原始文件名。

这些文件只是公开展示派生样例，不代表完整25庙高清档案已经公开。
